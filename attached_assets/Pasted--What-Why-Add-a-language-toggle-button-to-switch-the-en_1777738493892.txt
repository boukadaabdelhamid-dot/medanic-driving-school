ر تبديل اللغة عربي / فرنسي
What & Why
Add a language toggle button to switch the entire app UI between Arabic and French. The app is a Python/Tkinter driving school management system with all text currently hardcoded in Arabic. The user wants to let the operator choose their preferred language at runtime.

Done looks like
A clearly visible language toggle button (e.g. "🌐 FR / AR") appears in the title bar (top bar) of the app.
Clicking it switches all visible UI text — tab labels, column headers, form labels, buttons, status bar, messages — between Arabic (RTL) and French (LTR).
The window layout direction (RTL ↔ LTR) adjusts when switching languages.
The currently active language is remembered during the session (no persistence to disk needed).
All existing functionality (DB, PDF, printing) continues to work correctly in both languages.
Out of scope
Persisting the language choice across app restarts (config file / DB storage).
Translating PDF document content (only the UI toggles; PDFs can remain in Arabic for now).
Adding a third language.
Steps
Create translation dictionary — At the top of driving_school_single.py, define a TRANSLATIONS dict with two keys "ar" and "fr". Map every user-visible string (tab names, column headers, button labels, form field labels, status bar text, dialog messages, dropdown options, section titles) from Arabic to French. Cover all 9 tabs: Dashboard, School Info, Candidates, Instructors, Training Stages, Payments, Expenses, Reports, Documents.

Add language state and helper function — Add a global CURRENT_LANG = "ar" variable and a t(key) helper function that looks up the current language in TRANSLATIONS and falls back to the Arabic value if a French key is missing. Also add a set_lang(lang) function that updates CURRENT_LANG.

Add the toggle button to the title bar — In _title_bar(), add a ModernButton (or styled tk.Button) on the left side next to the date label. Its text shows "🌐 Français" when the app is in Arabic and "🌐 عربي" when in French. Clicking it calls a _switch_language() method.

Implement _switch_language() — This method updates CURRENT_LANG, destroys and rebuilds the title bar, notebook tabs, and status bar widgets (by calling _title_bar(), _build_tabs(), _status_bar() again after clearing the root window children), and also updates the window's tk direction setting (self.root.tk.call('tk', 'windowingsystem') is not needed; use self.root.option_add('*font', ...) or simply re-layout). Handle RTL/LTR by toggling widget anchor and justify options globally where needed.

Replace hardcoded strings with t() calls — Go through all Frame classes and replace hardcoded Arabic UI strings with t("key") calls so they pick up the correct language when widgets are built. Focus on: tab labels in _build_tabs(), column headers in all ttk.Treeview setups, tk.Label text values, ModernButton text values, ttk.LabelFrame text values, messagebox strings, and the status bar text.
