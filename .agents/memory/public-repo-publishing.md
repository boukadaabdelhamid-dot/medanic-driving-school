name: Public GitHub releases
description: Scope for publishing this project to a public repository.
---

Keep public releases to application source and the deployment configuration needed for Railway. Exclude PDFs, uploaded attachments, user-facing documentation files, and internal Replit agent notes. Keep only brand assets required for the application build.

**Why:** The user chose a public code-only repository push and explicitly excluded documents and attachments.

**How to apply:** Before any later public push, inspect the staged tree and commit history for documents, attachments, databases, and internal workspace files. Do not force-push.
